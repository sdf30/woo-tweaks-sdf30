# Tweak Tools for WooCommerce

Tweak Tools for WooCommerce est un plugin WooCommerce modulaire et ultra-léger conçu pour optimiser l'UI/UX du frontend, rationaliser le tunnel de vente et simplifier la gestion administrative de votre site e-commerce. Il est pensé pour être tres simpliste aussi bien sur les themes FSE (Full Site Editing) via le Site Editor, que les themes classiques. 

## Fonctionnalités Principales

- **Custom Labels** : Personnalisation dynamique des boutons d'ajout au panier.
- **Bouton En Savoir Plus** : Bouton supplémentaire entièrement compatible Full Site Editing (FSE).
- **Empty Cart Redirect** : Redirection automatique des paniers vides vers la boutique.
- **Checkout Fields Cleaner** : Nettoyage des champs superflus lors de la validation de commande.
- **Hide Components** : Masquage sélectif du SKU, des catégories et produits apparentés.
- **Bulk Price Manager** : Ajustement massif des prix via les actions groupées natives.
- **Custom CSS Engine** : Injection de styles personnalisés via un éditeur intégré (CodeMirror).
- **Module Manager** : Architecture modulaire permettant d'activer/désactiver chaque option indépendamment.

## Traduction

Le plugin est prêt à être traduit (i18n ready) et inclut un fichier `tweak-tools-sdf30.pot` dans le dossier `languages/`.

**Option 1 : Via Loco Translate (Recommandé pour les débutants)**
1. Installez et activez le plugin gratuit **Loco Translate**.
2. Allez dans *Loco Translate > Extensions* et sélectionnez **Tweak Tools for WooCommerce**.
3. Cliquez sur **Nouvelle langue**, choisissez votre langue et commencez à traduire directement depuis votre interface WordPress.

**Option 2 : Via Poedit (Recommandé pour les développeurs)**
1. Téléchargez et installez le logiciel gratuit **Poedit** sur votre ordinateur.
2. Ouvrez le fichier `languages/tweak-tools-sdf30.pot` avec Poedit.
3. Cliquez sur **Créer une nouvelle traduction** et choisissez votre langue.
4. Traduisez les chaînes et sauvegardez. Poedit génèrera les fichiers `.po` et `.mo` que vous devrez placer dans le dossier `languages/` du plugin ou dans `wp-content/languages/plugins/`.
