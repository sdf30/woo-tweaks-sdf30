# Contribution au plugin Tweak Tools for WooCommerce

Merci de l'intérêt que vous portez à ce projet ! Toutes les contributions (rapports de bugs, suggestions de fonctionnalités, ou Pull Requests) sont les bienvenues.

## 🐛 Signaler un bug
Si vous rencontrez un problème, merci de créer une "Issue" sur notre dépôt en incluant :
- La version de WordPress et de WooCommerce que vous utilisez.
- Les étapes précises pour reproduire le bug.
- Des captures d'écran ou des logs d'erreurs (si applicable).

## 💡 Suggérer une fonctionnalité
Nous sommes ouverts aux nouvelles idées qui restent dans l'esprit "léger et modulaire" du plugin. Créez une Issue et décrivez votre idée le plus en détail possible.

## 🛠️ Proposer du code (Pull Request)
1. Forkez le dépôt.
2. Créez une branche pour votre fonctionnalité ou correction : `git checkout -b feature/ma-super-fonctionnalite` ou `git checkout -b fix/nom-du-bug`.
3. Assurez-vous de respecter les standards de code WordPress (`phpcs` est configuré sur ce projet).
4. Commitez vos changements avec un message clair : `TYPE: description` (ex: `FEAT: ajout d'une nouvelle option pour le module DirectCheckout`).
5. Poussez votre branche : `git push origin feature/ma-super-fonctionnalite`.
6. Ouvrez une Pull Request.

Merci pour votre aide !
