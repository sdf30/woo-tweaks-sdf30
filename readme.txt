== Description ==

Woo Tweaks Tools (by OPEN-SDF) is a premium-grade utility suite designed to fill the gaps in standard WooCommerce installations. Instead of dozens of small plugins, get one lightweight, modular solution.

**Key Modules:**
*   **Promo Urgency Badges**: Boost conversions with scarcity messaging on sales items. Supports FSE and Classic hooks.
*   **Smart Stock Messaging**: Dynamically display urgent stock alerts (e.g., "🔥 Only 3 left!").
*   **Bulk Price Manager**: Edit prices massively directly from the product list (Fixed, Percentage, Rounded).
*   **Direct Checkout**: Skip the cart or add a secondary "Buy Now" button.
*   **Account UX**: Cleaner profile pages and retractable credentials sections.
*   **Custom CSS**: Integrated editor for site-wide styling.
*   **Stock Status Shortcuts**: Manage stock availability with AJAX actions in the admin list.

== Installation ==

1. Upload the plugin folder to the `/wp-content/plugins/` directory, or install through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Go to WooCommerce > Settings > Woo Tweaks to configure your modules.

== Frequently Asked Questions ==

= Does this work with Block Themes (FSE)? =
Yes! We have dedicated Gutenberg blocks for Promo Urgency and Direct Checkout that you can use in your single product templates.

= Is it translation ready? =
Absolutely. The plugin is fully localized using the `woo-tweaks-tools` text domain.
